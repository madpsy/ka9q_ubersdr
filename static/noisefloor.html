📶 SNR API

Everything in the SNR Monitor comes from one endpoint you can call yourself, from a script, a spreadsheet or a logging tool. The examples below use this receiver's address () and your current selection, so they work as pasted.

Endpoints

RequestReturns
GET /api/snr?range=<name>One reading for a named range.
GET /api/snr?lo=<kHz>&hi=<kHz>One reading for a custom range.
GET /api/snr/rangesEvery named range, with its span, source and bin width.

Parameters

NameMeaning
rangeAn amateur band configured on this receiver (e.g. 20m, 6m if enabled), a broadcast band (bc-lw, bc-mw, bc120m … bc11m), all (0–30 MHz) or hf (1.8–30 MHz). Not case-sensitive.
lo, hiCustom edges in kHz, decimals allowed. Use instead of range, not with it. Must lie within the receiver's coverage, which can extend above 30 MHz.
avgOptional. Seconds to average (0–60, whole numbers). 0 or omitted uses the latest sweep only. Averaging smooths p95 at the cost of reacting slower.

Response fields

FieldMeaning
snr_dbp95 − p5, the same measure the KiwiSDR SNR page uses.
p5_db, p10_db, p50_db, p95_dbPercentiles of the bins in range. p5 is the noise floor estimate, p95 the signal peaks.
min_db, max_db, mean_dbExtremes and mean of the bins.
occupancy_pctShare of bins more than 10 dB above p5.
source, bin_width_hz, binsWhat the reading was measured from: a band's own channel (fine bins) or wideband (coarse bins).
avg_sec, samplesThe averaging window asked for, and how many sweeps it held.
timestampWhen the newest sweep was taken (UTC). Unchanged between two polls means no new sweep yet.
range, lo_khz, hi_khzWhat was asked for.

Good to know

  • New sweeps arrive about once a second, so polling faster than that returns the same reading.
  • Requests are limited to 4 a second per address, across all ranges.
  • Only compare readings with the same source and bin_width_hz. Percentiles depend on bin width, so 20m from its own channel won't match 20m sliced from the wideband spectrum. A range that fits inside a band always uses that band's channel.
  • A range must cover at least 10 bins; narrower ranges are refused.
  • Nothing is stored on the server. Keep a script running, or use the CSV button, to record a session.

Comparing antennas from a script

The page's capture tool runs in the browser. To do the same from a script, log readings for each antenna to its own file (the CSV example below), then compare the averages of snr_db, p5_db and p95_db between files. Use the same range and avg for both, or the numbers won't be comparable.
